## 1. Overview

Week 04 focuses on practical penetration testing activities involving initial reconnaissance, PDF security analysis, identifying potential sensitive information exposure, and preparing a structured penetration testing report.

The practical exercises were performed against the designated training environment, Mediroza General Hospital.

**Target:** `https://medirozahospital.com`

## 2. Modules Covered

| Module | Description |
|---|---|
| M1 – Initial Access | Initial reconnaissance and information gathering |
| M2 – Data Extraction | PDF password security analysis and metadata examination |
| M3 – Critical Data Exposure | Identification and assessment of potentially exposed directories and backup resources |
| M4 – Penetration Testing Report | Documentation of findings, risks, and remediation recommendations |

## 4. Practical Implementation

### M1 – Initial Access
Initial reconnaissance and information gathering to understand the target's publicly available technical information.

### M2 – Data Extraction
Performed PDF password security analysis, hash extraction, password auditing, decryption of the authorized training document, and metadata examination.

### M3 – Critical Data Exposure
Examined the website's robots.txt file and investigated the disclosed directory paths to assess potential information exposure.

### M4 – Penetration Testing Report
Prepared a structured report documenting observations, security implications, risk levels, and remediation recommendations.

## 5. Key Learning Outcomes

- Understood the initial reconnaissance process.
- Practiced PDF password security assessment.
- Learned to examine PDF metadata.
- Identified how publicly disclosed directory paths can reveal potential exposure.
- Understood the security risks associated with publicly accessible backup files.
- Improved technical documentation and vulnerability reporting skills.

## 6. Conclusion

Week 04 provided practical exposure to reconnaissance, document security assessment, information disclosure analysis, and penetration testing documentation. These exercises strengthened my understanding of identifying potential security weaknesses and communicating findings responsibly.
